# Play As Krystal

A mod for **Foxhollow**, the native PC port of **Star Fox Adventures**, that lets you play as everyones favourite blue vixen Krystal throughout the entire game.

## Features

- Krystal’s model replaces Fox during gameplay and cutscenes.
- All Fox gameplay functionality is retained, including staff combat and abilities.
- Existing Krystal voice clips replace supported Fox sounds
- Krystal’s portrait replaces Fox’s on the Moon Mountain Pass and Cape Claw poison meters.


## Installation

1. Download the most recent release ZIP.
2. Extract the `play-as-krystal` folder into your Foxhollow launcher’s mods directory.
3. Enable **Play As Krystal** in the launcher.
4. Restart the game.


## Voice Replacements

The mod uses existing Krystal voice recordings from the game to replace the underlying fox character. Some sounds use a suitable alternative where an exact equivalent is unavailable.
Cutscene spoken dialogue and the voicelines for "Stay, Ball and Flame" tricky commands remain as there is no suitable replacements for Krystal.

## Compatibility

The mod is natively compatable with the **Discord Rich Presence** mod. it is not required however to use this mod.

Mods that modify the player model, animations or sound playback may conflict.
